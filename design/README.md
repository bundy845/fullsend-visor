# Design index

## Current direction

A simple desktop utility controls one rectangular dashboard in VR. Keep connection/source status visible, label placement controls with units, and group source selection, VR connection, placement, and persistence actions. Provide keyboard access and clear error/retry text.

There are no approved UI mockups yet. The fixed-dashboard specification is authoritative for behavior. Add mockups here when they materially clarify the implementation; do not create placeholder design assets.
